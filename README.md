# CSE 434 Socket-Full — Group 75 (Bassam Aljalawi)

Youtube Demo Link: https://www.youtube.com/watch?v=qAdoLBEnZAw


A distributed hash table (DHT) of storm-event data, built in Python 3, UDP, ports 37500–37999.

```
python3 manager.py 37500
python3 peer.py <manager-IP> 37500
```

Peer commands: `register`, `setup-dht`, `query-dht`, `leave-dht`, `join-dht`, `teardown-dht`, `deregister`.
